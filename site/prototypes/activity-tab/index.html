Activity tab — one surface for monitoring + upgrade history
Static prototype for the Surface sidebar. The Monitor and Upgrades tabs collapse into one read-first Activity tab. The entity header now borrows the standalone monitoring page's vocabulary — the pm-badge type tag and the live state grid (Owner / Paused / Impl / Threshold · Last event · ● active) — instead of repeating TVL, role, and audit facts that already live on Detail / Audits. Below the header: alert toggles (the old Monitor tab), then one timeline merging upgrades + governance events, split by the enrollment boundary (above = captured live; below = upgrade-only backfill). A proxy is one entity with one event stream (all logs fire at the proxy address); the implementation shows up as the current-logic pointer and as per-event "under impl X" attribution. Operator-only controls (re-enroll, webhook counts) are gone — this is user-facing.
