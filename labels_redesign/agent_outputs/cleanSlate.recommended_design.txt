WINNER: H5 — a two-layer claims-registry design (facts substrate + gated standards/idiom claims), assembled from the measured-good parts of H2 and H3, with H4's existing policy-stage cross-contract pass retained for claims that need callee identity, and H1's two proven components (guess-tier deletion, selector canonicalization) subsumed.

WHAT A LABEL *IS*: there are exactly two kinds of emitted statement, and both are objects, not strings. (K1) FACT — a record checkable directly against Slither IR by a deterministic predicate: state-write {var, declared_type, granularity: var|namespaced_struct|assembly_slot, hygiene_class: normal|constant|storage_location_pseudo|reentrancy_guard}, var-role {gate-bool-for-N-state-changing-fns via predicate-leaf role='pause', caller-authority-equality via leaf role='caller_authority' (operand var named — so 'rotates caller-authority address `pauser`' renders instead of a fake 'ownership transfer'), callee-pointer-invoked-by-sibling-entry (the measured-clean _writes_hook_reference signal), fallback-delegatecall-read, one_shot latch via one_shot leaves}, value-flow {low-level value call, Transfer IR (.transfer()/.send() — fixes the WETH9.withdraw miss), callee ERC-20 selector}, sink {kind, target, selector, origin: body|modifier} (origin fixes the Teller.pause requiresAuth pollution). Facts are produced by build_effects hardened with builder-level hygiene: constants, *StorageLocation/*_SLOT pseudo-vars, and reentrancy-role vars can never appear as role facts (each exclusion measured necessary in derive_sim.py). (K2) CLAIM — {claim_id, tier ∈ {standard_exact, idiom_structural}, evidence: {gate_facts, trigger}} minted ONLY by a registry matcher whose entry carries: written claim text; a machine-checkable evidence spec = contract-level GATE (mandated sibling selectors, write-target identity, sink shape — e.g. uups := proxiableUUID() present; safe := getThreshold+getOwners+execTransaction; pausable := pause()+unpause()+({paused,isPaused,_paused} write identity or paused view); wards := rely+deny+wards write identity) plus a per-function trigger (canonical selector or fact-pattern); ≥1 positive real-contract fixture; ≥1 counterexample fixture (composeQueue-class); an approved corpus A/B diff. Initial registry = the 18 matchers measured in h3sim.py (erc20, weth, ownable/2step, solady_ownable, access_control, access_control_dar, pausable, oz_pausable_var, uups, proxy_shell, safe, oz_timelock, solmate_auth, solmate_roles, maker_wards, comp_votes, fiattoken, lz_oapp) + callee_pointer.rotate idiom + exec.arbitrary gates. Measured yield on the 27-contract corpus: 154 exact claims / 415 state-changing fns, 0 observed false claims, recovering implementation_update (17 vs 0 today), timelock ops (6 vs 0), Safe signer/module/guard semantics (12 vs 0/wrong), Solady + OZ v5 ownership (ghost-immune), Maker wards, Comp delegation. (K3) A thin POLICY-STAGE augmentation (existing cross_contract.py path, claims instead of labels) adds cross-contract claims that need callee identity: beacon upgrade (upgradeEtherFiNode), callee mint/burn propagation — computed downstream because the evidence lives downstream, per H4's one correct insight.

HOW EACH IS PRODUCED: facts in effects.py from IR + predicate-leaf roles (single source for role discrimination — the taxonomy that already exists at the leaf level: caller_authority/pause/reentrancy/business/time/one_shot); claims in a new registry module invoked after build_effects with (contract, facts, predicate_trees) — a pure function of source; policy augmentation in policy_worker as today. The deleted machinery: _writes_unclassified_address_pointer (+fallback :727), _is_address_like_state_var, _writes_owner_like_address, _writes_authority_reference, _detect_supply_change_pattern, the ownership post-pass as sole emitter (kept only as corroborating fact 'caller-authority var write'), _writes_pause_like_bool and pause_info as claim sources (both measured imprecise; they persist as fact inputs).

EVIDENCE STANDARDS (written, per statement kind): facts — the predicate over IR must evaluate true (test = re-run predicate); standard_exact claims — gate + trigger predicates over facts must evaluate true AND the standard's semantics are the claim's semantics by the standard's own documentation (test = fixtures); idiom_structural claims — same shape, for de-facto idioms (wards, callee-pointer, weth), always with counterexample fixtures. UNKNOWN = silence + fact text; the design chooses SILENCE over marked-guess, because the marked-guess variant was measured to be exactly today's hook_update (1/69) and the consumers that matter already treat coarse labels as noise (primary_controller.py:161-164, company_overview.py:940-942).
