# Retired verdict-policy regression sources

`regressions.json` preserves 111 literal Solidity snippets from the pre-restructure test files, with their
original filename and line number. Their original tests and setup code are recoverable at Git revision
`5d7bca54`. Some snippets are fragments combined with other snippets by those tests.

This archive preserves bug examples; it is not an executable oracle and is not counted in passing test totals.
The retained differential tests and the new formula/projection/composition tests are the current executable checks.
